# ✈️ Boeing Supplier Data Analysis

## 🧠 Description
Boeing is a global aerospace company dedicated to the design, manufacture, and sale of commercial airplanes, defense systems, and aerospace technology. As one of the world's largest aircraft manufacturers, Boeing operates through a complex global supply chain.

This project analyzes a dataset provided by Boeing containing information about its suppliers, including their names, countries, and business categories. The goal is to perform exploratory data analysis (EDA) to uncover insights about Boeing’s supplier network, geographic distribution, and supplier specialization.

The results can support strategic decisions related to supply chain management, risk diversification, and supplier sourcing.

## ⚙️ Technologies Used

- Pandas  
- NumPy  
- Matplotlib  
- Seaborn
